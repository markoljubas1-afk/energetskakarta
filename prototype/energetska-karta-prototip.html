Demo podaci

Prikaz dizajna. Brojke su izmišljene, ali međusobno usklađene: proizvodnja je uvijek jednaka potrošnji uvećanoj za izvoz. Stvarni podaci dolaze iz ENTSO-E i GIE u sljedećoj fazi.

Ovo je prototip nadzorne ploče, ne karta. Sama karta sa svim slojevima (dalekovodi, trafostanice, elektrane, podatkovni centri, distribucijska mreža, punionice, cjevovodi, tokovi i cijene) je stvarna aplikacija u mapi web/. Pokreće se jednom naredbom: cd web && npm install && npm run preview:local, pa localhost:4173 — s testnim podacima, bez ikakvih ključeva. Ova stranica ostaje kao dogovoreni izgled nadzorne ploče koja dolazi u Fazi 6 sa stvarnim ENTSO-E podacima.
